# MVP Scope

## Included

- Mobile-first storefront later
- Product catalog
- Product categories
- Ready-to-serve cocktail packs
- Cocktail kits
- Mocktail packs
- Event-oriented bundles
- Scheduled checkout
- Customer data capture
- Address capture
- Delivery zone selection
- Manual payment method selection
- Order status tracking
- Admin order management
- Age confirmation
- Delivery verification
- Order status history
- Basic operational dashboard
- Seed data
- Responsible drinking messaging
- Configurable delivery zones
- Configurable operating schedule

## Excluded

- Standalone liquor bottle sales
- Native mobile app
- Marketplace model
- Multiple local operators in MVP
- Real-time driver map
- Automatic WhatsApp API integration
- Stripe or card payments
- Loyalty program
- Advanced inventory
- AI recommendations
- Complex promotions
- Multi-driver dispatch system
- Photo or document storage for ID
- Kubernetes
- Microservices
- Celery
- Redis
- Complex cloud infrastructure
- Docker as a required local dependency

## MVP Success Metrics

After 30 to 50 real orders, evaluate:

- Average ticket, target 35 USD or more
- Gross margin, target 50 percent or more
- Repeat purchase, target 20 to 30 percent
- Most sold products
- Best delivery zones
- Strongest days
- Preparation time
- Delivery issues
- Failed verification cases
- Cancellation reasons
- Customer feedback
- WhatsApp/order conversion
